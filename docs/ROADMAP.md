## Критерии приёмки (согласовано с преподавателем)

- MVP по PDF: игра 5–10 мин с одной механикой, 3–4 команды, калибровка, обучение, обратная связь,
  отмена ошибочной команды, обычное управление для сравнения.
- Каналы: наклоны/жесты телефоном обязательны; камера и прочие датчики — плюс («чем больше, тем интереснее»).
- Эксперимент: сравнение алгоритмов на одинаковых записях + тест с 10–12 участниками с чередованием порядка.
- Метрики: время заданий, ошибки, ложные срабатывания, скорость обучения, задержка, впечатления.
- Отрицательный результат принимается при корректном эксперименте и объяснении.
