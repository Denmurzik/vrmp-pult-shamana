# Спецификация: «Пульт шамана» — Охота на духов

Android-игра на 5–10 минут, в которой телефон — прибор для поиска невидимых духов.
Игрок поворачивается с телефоном, ориентируется по вибрации и звуку и выполняет
жесты, чтобы ловить и изгонять духов. Игра — экспериментальная установка: правила
и задания постоянны, меняется только источник команд (см. [RESEARCH.md](RESEARCH.md)).

## 1. Игровой цикл

- **Раунд** 45–60 с. Вокруг игрока (360° по рысканию/yaw) в скрытых направлениях появляются духи.
- **Сканирование** — непрерывное: направление телефона = направление луча сканера (конус ±15°).
- **Обратная связь о близости**: чем ближе луч к духу, тем сильнее/чаще вибрация и выше тон звука.
  На экране — радар-дуга, показывающая только то, что попало в конус (без полной карты).
- **Типы духов**:
  - *Блуждающий* — его нужно **поймать**.
  - *Злой* — его нужно **изгнать**.
- Команда засчитывается, только если дух в конусе сканера. Неверная команда или промах = ошибка.
- **Атака злого духа**: характерный вибро-паттерн + звук; у игрока 1.5 с, чтобы **спрятаться**
  (накрыть датчик приближения ладонью), иначе теряет жизнь.
- **Туман**: в некоторых раундах конус сужается; **дунуть в микрофон** (громкость выше порога ≥ 300 мс)
  — туман рассеивается на 5 с.
- **Ловушки**: два типа (кнопки громкости ±), блуждающие духи двух цветов требуют свою ловушку.
- **Алтарь**: между раундами подключение зарядки пополняет ману (мана тратится на попытку поимки).
- Сид раунда фиксирован: одинаковые сид → одинаковая последовательность духов.

## 2. Команды и каналы ввода

| Команда | IMU (пороги / DTW) | Камера (жест рукой) | Тач (базовое управление) |
|---|---|---|---|
| Скан | поворот корпуса (ориентация) | поворот корпуса (ориентация) | горизонтальный свайп |
| Поймать | резкий рывок телефона вверх | сжать открытую ладонь в кулак | кнопка «Поймать» |
| Изгнать | круг телефоном | круг кончиком указательного пальца | кнопка «Изгнать» |
| Отмена | встряхивание ≤ 2 с после команды | помахать ладонью | кнопка «Отмена» |

Жесты подобраны по сложности: рывок — простой (ожидаем, что пороги справятся),
круг — траекторный (ожидаем преимущество DTW), встряхивание — периодический.

Доп. события (только игровой режим, **отключены в режиме эксперимента**, чтобы условия были равны):

| Источник | Действие |
|---|---|
| Датчик приближения (накрыть) | спрятаться от атаки |
| Микрофон (громкость, без распознавания речи) | рассеять туман |
| Кнопки громкости | сменить ловушку |
| Подключение зарядки | алтарь: пополнить ману |

## 3. Жизненный цикл команды

Каждый распознаватель выдаёт события в общий `CommandArbiter` с понятными состояниями:

```
IDLE → CANDIDATE → CONFIRMED → (окно отмены 2 с) → COMMITTED
                 ↘ REJECTED            ↘ CANCELLED (жест/кнопка «Отмена»)
```

- `CANDIDATE` — движение похоже на жест: лёгкий тик-вибро + индикатор на экране.
- `CONFIRMED` — команда применяется к игре **сразу**, звучит отклик.
- В окне отмены «Отмена» откатывает действие (дух возвращается), это не считается ошибкой распознавания,
  но логируется как отменённая команда.
- После `CONFIRMED` — рефрактерный период 400 мс (защита от двойных срабатываний).

## 4. Калибровка и обучение

1. **Нулевое направление**: «Направь телефон вперёд и нажми OK».
2. **Эталоны жестов**: по 5 повторов каждого IMU-жеста (нужны DTW) и пороговая проверка.
3. **Камера**: разрешение на фронтальную камеру, живой предпросмотр со скелетом и FPS, затем проверка освещения и видимости руки. Камерный шаг можно пропустить для IMU.
4. **Обучение**: интерактивный тренажёр — по каждому жесту 3 успешных выполнения с подсказками.

## 5. Режимы приложения

- **Игра** — полный режим со всеми датчиками.
- **Эксперимент** — выбор участника (анонимный ID `P01`…), условия и сида; отключены доп. события;
  всё пишется в лог сессии.
- **Запись датасета** — приложение показывает подсказку («Круг, быстро»), отсчёт, окно записи 2.5 с,
  сохраняет размеченную запись. Отдельно — «нулевые» записи (ходьба, взять со стола, карман, печать) по 2 мин.
- **Настройки** — выбор распознавателя, параметры порогов/DTW, отладочный оверлей сигналов.

## 6. Платформа

Android, Kotlin, Jetpack Compose, **Material 3 Expressive** (material3 1.5.x), minSdk 26, compileSdk 37, MediaPipe Tasks Vision (Hand Landmarker, LIVE_STREAM),
CameraX, датчики `TYPE_GAME_ROTATION_VECTOR`, `TYPE_LINEAR_ACCELERATION`, `TYPE_GYROSCOPE`,
`TYPE_PROXIMITY`. Ориентация — по `GAME_ROTATION_VECTOR` (без магнитометра: нет скачков компаса в помещении).
