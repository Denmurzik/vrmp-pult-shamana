# ВРМП — Пульт шамана

RnD-проект курса ВРМП (НГУ ФИТ, 2026). Телефон — прибор для поиска невидимых духов:
поворот ведёт сканер, вибрация сообщает о близости, жест ловит или изгоняет духа.

**Исследовательский вопрос:** окупается ли усложнение распознавания жестов? Сравниваем
пороговые правила по IMU, DTW по эталонам и жесты рукой через камеру (MediaPipe) —
офлайн на записях и в тесте с 12 участниками против обычного тач-управления.
